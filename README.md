AI Driver Drowsiness & Distraction Detection

A real-time driver monitoring system that combines Computer Vision, Machine Learning, and a Flask dashboard to detect driver behavior as Attentive, Drowsy, or Yawning.

Dataset

The project uses data from subjects S01 and S02.

ML training conditions:

normal

glasses

mask

Low-light samples were intentionally excluded from ML training. The runtime application includes lighting-aware processing.

Dataset images are not included in the Git repository. Keep the dataset locally in the dataset/ directory and follow the expected folder structure used by feature_extractor_combined.py.

Installation

Create and activate a virtual environment:

python -m venv venv
.\venv\Scripts\Activate.ps1

Install dependencies:

pip install -r requirements.txt

Run the Application

From the project root:

python main.py

The application starts the webcam detector and the integrated Flask dashboard.

Open:

http://127.0.0.1:5000

Train the Model

If the feature CSV needs to be regenerated:

python feature_extractor_combined.py

Then train:

python train_model_combined.py

The trained model and evaluation files are generated by the training pipeline.

Important Design Decisions

Adaptive EAR Calibration

The system estimates an initial personal EAR baseline instead of relying entirely on one universal eye-closure threshold.

Temporal Smoothing

Recent predictions are evaluated over multiple frames so an isolated noisy prediction does not immediately change the final state.

Yawning Robustness

Yawning detection combines mouth opening, jaw movement and sustained-frame conditions to reduce false positives from ordinary mouth movement.

CV + AI Fusion

The final driver state uses both rule-based computer vision signals and machine-learning predictions rather than depending on a single signal.

Limitations

Current ML dataset contains only two subjects.

Subject-independent generalization has not yet been established.

Low-light samples were excluded from ML training.

Webcam quality, pose and environmental conditions can affect facial landmark extraction.

The current prototype is not a certified automotive safety system.

Note on Research Novelty

The project does not claim that EAR, MAR, MediaPipe, or Random Forest are individually new techniques. The contribution is the practical integration of established techniques into a real-time hybrid driver-monitoring system, including adaptive calibration, temporal stabilization, occlusion-aware yawning logic, AI confidence and explainable dashboard analytics.
